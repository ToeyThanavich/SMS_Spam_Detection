# SMS Spam Detection (NLP Project)
- Developed a machine learning model to classify SMS messages as spam or ham using NLP techniques
- Applied text preprocessing (tokenization, stopword removal, TF-IDF vectorization)
- Trained and evaluated models (Naive Bayes, SVM, Logistic Regression)

# ใช้ข้อมูลจากชุดข้อมูล SMS Spam Collection Dataset ซึ่งเผยแพร่ผ่าน Kaggle
Link:(https://www.kaggle.com/datasets/uciml/sms-spam-collection-dataset)
- โดยใช้ไฟล์ข้อมูลต้นฉบับชื่อ spam.csv และได้ทำการปรับสมดุลข้อมูล (balancing)
- เพื่อให้จำนวนข้อมูลประเภท ham และ spam เท่ากันซึ่งได้ไฟล์ใหม่ชื่อ spam_balanced.csv
